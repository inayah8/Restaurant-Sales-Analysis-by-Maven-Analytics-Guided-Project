# Restaurant-Sales-Analysis-by-Maven-Analytics-Guided-Project
Restaurant Sales Analysis by Maven Analytics Guided Project Menggunakan MySQL dan Excel

#### Tujuan
1. Menu mana yang harus dipromosikan?
2. Kategori cuisine mana yang paling menguntungkan?
3. Kapan jam sibuk sehingga perlu tambah staff?
4. Bagaimana mengoptimalkan strategi menu untuk naikkan revenue?

Project ini menjawab pertanyaan-pertanyaan tersebut menggunakan **SQL** untuk
analisis data dan **Excel** untuk visualisasi dashboard.

#### Sumber Dataset:
[Maven Analytics — Restaurant Orders](https://app.mavenanalytics.io/guided-projects/d7167b45-6317-49c9-b2bb-42e2a9e9c0bc)

#### Tools yang Digunakan

| Tools | Penggunaan |
|---|---|
| MySQL Workbench | Eksekusi query, JOIN, GROUP BY, agregasi, subquery |
| Microsoft Excel | Visualisasi data dan dashboard interaktif |

#### Business Questions
Section 1 — Menu Analysis
1. Berapa total item di menu? Berapa per kategori?
2. Menu apa yang termahal & termurah?
3. Berapa rata-rata harga per kategori?
4. Berapa menu Italian, dan apa yang termurah/termahal di kategori ini?

Section 2 — Order Analysis
1. Berapa rentang tanggal data?
2. Berapa total order & total item terjual?
3. Order mana yang punya item paling banyak?
4. Berapa order yang memiliki lebih dari 12 item?

Section 3 — Sales Performance
1. Menu apa yang paling & paling sedikit dipesan?
2. Kategori mana yang menghasilkan revenue tertinggi?

Section 4 — Time Analysis
1. Jam berapa restoran paling sibuk?
2. Hari apa yang paling ramai?
